风月酿研所 · 使用说明

Windows 桌面版

第一次用，按这个顺序走

  1. 新建配方：点右上角「新建」，或从「经典配方库」挑一款作为起点。
  2. 填参数：配方页左侧填批次量、糖化效率等，右侧「实时指标」会同步算出 OG、ABV、IBU、色度。
  3. 保存：点「保存配方」写入本机。下次打开还在，不会上传到任何服务器。
这个软件是完全离线的：所有计算和保存都在你自己的电脑上完成，不联网也能用。

数据存在哪、怎么备份

配方与设置保存在本机用户目录，不在软件安装目录里——所以卸载重装不会丢数据，但也意味着换电脑要自己拷贝。

两种备份方式，建议都留着：

  • 软件内导出：「设置 → 导出」，得到一份 JSON。恢复时用「设置 → 导入」，按 id 合并，同 id 保留较新的。
  • 自动备份：菜单「文件 → 立即备份数据」，或直接翻上面的备份目录。适合手滑改坏配方之后回滚查看。

常见问题

现象怎么办
双击后要等一两秒才出界面首次启动要解压程序本体，属正常；之后会快很多。
Windows 提示"已保护你的电脑"软件未购买数字签名证书，属正常。点「更多信息 → 仍要运行」，或右键属性勾选「解除锁定」。
杀毒软件报风险打包后的可执行文件偶发误报，加入信任即可。软件不联网、不写系统目录。
界面卡在"正在初始化酿造引擎"菜单「视图 → 重新加载」；仍不行就关掉重开。数据不会丢。
换了台电脑，配方没了用「设置 → 导入」选之前导出的 JSON；或把数据目录整个拷过去。
